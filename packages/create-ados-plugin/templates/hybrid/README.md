# Hello Hybrid Plugin

Skeleton hybrid plugin generated by `create-ados-plugin`. It is the
living "everything a plugin can do" example: an agent half (Python
subprocess) and a GCS half (TypeScript bundle in a sandboxed iframe),
wired together through the manifest `contributes` model.

## What this template demonstrates

- **A flight Skill** (`contributes.skills`): a toggle in the cockpit
  Skill Bar (default hotkey `h`). Arming writes the per-node `active`
  config; the agent reads it live and reports `hello.state`.
- **A node-detail tab** (`contributes.tabs`, slot `node.detail.tab`,
  narrowed to the `drone` profile): the GCS half mounts this iframe to
  show the live read-back from the agent.
- **Native declarative settings** (`contributes.parameters`): a `range`
  slider (`rate_hz`), an `enum` dropdown (`greeting`), and a **model
  picker** (`detector`, a `model` widget bound to `engine.detector`).
  The GCS renders these from the manifest. You write no UI for them; the
  agent reads the same per-node keys.
- **A model requirement** (`contributes.models`): the `coco-person`
  detection model with per-board variants (an RKNN build for RK3588, an
  ONNX CPU fallback). It is what the `detector` picker offers.

The agent and GCS halves agree on two strings: the per-node config key
`active` and the read-back event topic `hello.state`. Keep them in sync
across `manifest.yaml`, `gcs/src/plugin.ts`, and `agent/plugin.py`.

## Develop

```sh
pnpm install
pnpm test          # GCS vitest + agent pytest
pnpm build         # produces gcs/plugin.bundle.js
```

The agent tests run under `uv`; install the dev extras first:

```sh
cd agent && uv run --extra dev pytest
```

## Communication between halves

The agent half publishes events on the host event bus
(`ctx.events.publish`). The GCS half subscribes with
`ctx.events.subscribe('hello.state', ...)` once the operator grants the
matching permissions. See
`https://docs.altnautica.com/developers/event-hooks`.

## Pack and sign

Use `scripts/pack.sh` and `scripts/sign.sh` from
`altnautica/ADOSExtensions` to produce a signed `.adosplug`.
